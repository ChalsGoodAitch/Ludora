Ludora 1.0.0
============
A native WordPress block theme. Requires WordPress 6.8+ and PHP 8.2+.
Install through Appearance > Themes > Add New > Upload Theme. No build tools are required on hosting. Customize templates, styles, navigation and patterns through Appearance > Editor. Three complete homepage patterns are available under Ludora homepages. Insert one into a new page and select that page under Settings > Reading. No content or settings are changed on activation.

The optional Ludora Booking companion owns all venue data and booking behavior. Install it only if needed through Appearance > Install Plugins. WooCommerce is optional and only needed for the companion payment integration. No plugin is installed or activated automatically. The source checkout receives the companion ZIP during release packaging.

The parent theme is fully functional for ordinary pages and posts with no plugin. The Ludora Child example demonstrates a theme.json button customization. Use a child theme for permanent code changes; Site Editor changes are stored by WordPress.

System fonts are used with no external font or asset requests. This theme ships no photography. Demo photographs and credits belong to the optional companion importer.
